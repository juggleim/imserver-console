## ADDED Requirements

### Requirement: 实时统计入口
系统 SHALL 在数据统计菜单中提供实时消息统计入口，并通过带 `app_key` 的独立路由打开页面。

#### Scenario: 从菜单进入实时统计
- **WHEN** 已登录用户在某个应用下点击实时消息统计菜单
- **THEN** 系统打开该应用对应的实时消息统计页面

### Requirement: 实时采集开关
系统 SHALL 展示并允许更新应用配置 `open_real_time_msg_statistic`，且开关关闭时不查询实时统计数据。

#### Scenario: 开启实时统计
- **WHEN** 用户将实时统计开关由关闭切换为开启且保存成功
- **THEN** 系统更新应用配置并加载默认时间范围的实时统计数据

#### Scenario: 关闭实时统计
- **WHEN** 用户将实时统计开关切换为关闭且保存成功
- **THEN** 系统隐藏查询控件和图表并停止发起实时统计查询

### Requirement: 频道和时间范围查询
系统 SHALL 支持查询单聊、群聊和聊天室的实时统计，并支持最近 15 分钟、1 小时、6 小时、12 小时、1 天、3 天以及不超过 3 天的自定义时间范围。

#### Scenario: 使用快捷范围查询
- **WHEN** 用户选择一个快捷范围或切换频道
- **THEN** 系统使用当前应用、频道和毫秒时间戳范围调用实时统计接口

#### Scenario: 拒绝无效范围
- **WHEN** 用户选择结束时间不晚于开始时间或跨度超过 3 天的范围
- **THEN** 系统显示错误提示且不发送统计查询

### Requirement: 实时统计图表
系统 SHALL 以时间轴折线图展示上行、下行、分发三组每秒平均消息数，并按照查询跨度使用与后端一致的时间桶。

#### Scenario: 展示连续时间序列
- **WHEN** 后端只返回部分时间桶的数据
- **THEN** 系统为范围内缺失的时间桶补零，并将三组数据按同一时间轴展示

#### Scenario: 展示精确数值
- **WHEN** 返回的每秒平均消息数包含小数
- **THEN** 图表纵轴和提示框最多显示两位小数而不强制取整

### Requirement: 双语和嵌入式交付
系统 SHALL 为新增用户界面提供中文和英文文案，并重新生成供 Go 嵌入的前端构建产物。

#### Scenario: 切换界面语言
- **WHEN** 用户将界面语言切换为中文或英文
- **THEN** 实时统计菜单、控件、错误和图例使用对应语言显示

#### Scenario: 构建 Console
- **WHEN** 项目执行前端生产构建
- **THEN** `webconsole/web/dist` 包含实时统计路由及页面资源
